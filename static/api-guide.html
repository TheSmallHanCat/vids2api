← Vids2API API 指南

认证与通用约定

  • Base URL：http://your-host:8687
  • 鉴权：Authorization: Bearer YOUR_API_KEY（也支持 x-goog-api-key 头或 ?key= 参数）
  • 所有生成端点必须携带 Idempotency-Key 头（1-200 字符）。同键同参重放原收据，同键异参返回 409 冲突。
  • 收据一旦落在某账号（含失败），永不换号补发；未知接受状态只读不重发。

模型

curl -H "Authorization: Bearer $KEY" http://localhost:8687/v1/models

返回 vids-image、vids-speech、vids-video 三个模型及能力表（比例 / 时长 / 尺寸 / 声线）。

图片生成

curl -X POST http://localhost:8687/v1/images/generations \
  -H "Authorization: Bearer $KEY" \
  -H "Idempotency-Key: demo-key-1" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"一只戴宇航员头盔的柴犬","n":1,"aspect_ratio":"16:9","style":"photography"}'

支持 response_format: "url" | "b64_json"。图片编辑用 POST /v1/images/edits（multipart，字段 image + prompt）。

语音合成

curl -X POST http://localhost:8687/v1/audio/speech \
  -H "Authorization: Bearer $KEY" \
  -H "Idempotency-Key: demo-key-2" \
  -H "Content-Type: application/json" \
  -d '{"input":"欢迎使用 vids2api","voice":"Puck"}' \
  --output speech.wav

完成即返回 WAV 文件；未就绪返回 202 与收据，稍后经收据端点重试下载。

视频生成

curl -X POST http://localhost:8687/v1/videos \
  -H "Authorization: Bearer $KEY" \
  -H "Idempotency-Key: demo-key-3" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"雨夜霓虹街道上的赛博朋克追踪镜头","seconds":4,"size":"1280x720"}'
端点说明
POST /v1/videos提交任务（JSON 或 multipart：input_video MP4 ≤50MiB、input_reference[] 参考图）
GET /v1/videos任务列表（limit / after / order）
GET /v1/videos/{id}任务状态
GET /v1/videos/{id}/content下载完成的 MP4
GET /v1/vids/generations/{id}原始生成收据
POST /v1/vids/generations/{id}/download恢复失败的结果下载（不重复计费）

模式：text / animate / ingredients / edit / extend / upscale；编辑、续写、放大可通过 source_id 引用已完成视频或直接上传 video_base64。

错误结构

{
  "error": {
    "message": "All eligible Vids accounts are busy",
    "type": "invalid_request_error",
    "code": "busy",
    "param": null
  }
}

常见 code：busy（全部账号在途）、quota_exhausted（配额耗尽）、session_unavailable（无可用会话）、idempotency_conflict（幂等键冲突）。
